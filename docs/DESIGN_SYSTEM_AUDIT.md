# Design System Audit

## Preset

- Preset code: `b1iABXArHn`
- Source of truth: `components.json` generated by `pnpm dlx shadcn@latest init --preset b1iABXArHn --template next`

## Component Base

- Base component system: shadcn/ui on top of `@base-ui/react`
- UI style: `base-maia`
- Icon library: `lucide`
- Tailwind integration: CSS variables with `shadcn/tailwind.css`

## Typography

- Sans font variable: `--font-sans`
- Heading font variable: `--font-heading`
- Mono font variable: `--font-mono`
- Generated fonts in `app/layout.tsx`:
  - `Outfit` assigned to `--font-sans`
  - `Roboto` assigned to `--font-heading`
  - `Geist_Mono` assigned to `--font-mono`

## Color System

- Base color: `olive`
- Semantic tokens are defined in `app/globals.css`
- Theme uses `background`, `foreground`, `card`, `popover`, `primary`, `secondary`, `muted`, `accent`, `destructive`, `border`, `input`, `ring`
- Sidebar token set is also generated and wired through CSS variables

## Radius

- Global radius token: `--radius: 0.625rem`
- Derived tokens:
  - `--radius-sm`
  - `--radius-md`
  - `--radius-lg`
  - `--radius-xl`
  - `--radius-2xl`
  - `--radius-3xl`
  - `--radius-4xl`

## CSS Variable Strategy

- `:root` defines the light theme tokens
- `.dark` defines the dark theme tokens
- `@theme inline` maps CSS variables into Tailwind theme tokens
- `@layer base` applies border, ring, background, and foreground defaults

## Dark Mode

- Enabled through `next-themes`
- `ThemeProvider` uses `attribute="class"`
- Dark mode class is supported globally through the preset's CSS variables
