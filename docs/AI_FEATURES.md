# AI Features

Master Bakery now includes safe customer-facing AI entry points:

- Cake Serving Calculator at `/cake-serving-calculator`
- Master AI Assistant at `/ai-assistant` and the floating launcher
- Custom Cake Requirement Summary on `/custom-cake`
- Tamil, English, and Tanglish voice transcript review in the assistant

The current implementation works without provider credentials by using deterministic catalogue and serving-rule fallbacks.
